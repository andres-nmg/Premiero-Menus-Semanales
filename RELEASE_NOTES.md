## Texto para la Release

## Premiero Menús Semanales 3.0.0

Esta versión transforma el plugin original en una solución genérica, abierta y reutilizable para gestionar menús semanales en cualquier sitio WordPress.

### Cambios principales

- Nueva identidad **Premiero Menús Semanales**, sin referencias a proyectos o clientes concretos.
- Administración unificada mediante las pestañas Menús, Calendario, Shortcodes, Apariencia, Ajustes y Acerca de.
- Calendario visual para organizar las próximas semanas.
- La semana actual aparece siempre en primer lugar y permite abrir directamente su menú.
- Editor tipo hoja de cálculo con pegado desde Excel, importación y exportación CSV.
- Nuevo shortcode recomendado `[menu_semanal]` con vistas para hoy, fin de semana y acordeón.
- Compatibilidad con todos los shortcodes y datos de la versión 2.8.
- Personalización de colores, tipografía, tamaños, bordes y separación con vista previa.
- Mejoras de seguridad, zona horaria, carga de recursos y comportamiento responsive.
- Actualizaciones automáticas desde GitHub Releases.

### Requisitos

- WordPress 5.8 o posterior.
- PHP 7.4 o posterior.

### Instalación

Descarga `premiero-menus-semanales.zip` de los archivos adjuntos de esta Release e instálalo desde `Plugins > Añadir plugin > Subir plugin`.

Si actualizas desde Menús Semanales 2.8, los menús, el calendario y los shortcodes existentes se conservan.

> El ZIP instalable se adjunta automáticamente cuando finaliza el workflow **Build WordPress plugin release**.
